# HiddenStats

SPT 4.1.6（EFT 0.16.9.40743）客户端模组：把武器的隐藏属性显示到物品检视窗和武器改装界面，
数值按游戏自己的公式计算（组装后的实际值），并参与原版的装配件预览。

只需客户端（BepInEx 插件），不需要服务端模组。可与 RaidIntel 同时使用。

## 功能

- **隐藏属性条**（会随配件 / 弹药 / 弹匣 / 耐久变化，紧接原版属性条之后）：
  - 故障率/发：组装后实际值，悬停查看耐久、弹药、弹匣分项与不同耐久下的参考值；
    耐久 93%~100% 时游戏不会触发这三类故障，显示为 0。
  - 每发耐久损耗、每发升温、散热系数、耐久精度惩罚。
  - 枪声距离：AI 能听到你开枪的距离。游戏实际只看是否装有消音器（或自带消音的枪管），
    枪械与配件的「开火声音」数值游戏并不使用。
- **装配件预览**：拖动或悬停配件时，隐藏属性条与原版属性条一样闪烁显示变化段，
  数值后附带蓝色（变好）/ 红色（变差）增减。
- **隐藏属性小格**（只由枪型决定，紧接原版小格之后）：故障类型、后坐方向 ±散布、后坐回正、
  后坐阻尼、镜头后坐、稳定发数、半自动射速、空仓挂机、可单独压膛、可架枪。
- **弹匣**：故障率的具体数值（原版只显示等级）。
- **压缩原版属性区**（检视窗）：属性条两列排列（窗口过窄时自动单列），降低行高、缩小字号。
- **武器改装 / 编辑预设界面**：左下属性面板同样显示上述隐藏属性（不压缩），选配件时同样预览。

鼠标悬停任意隐藏属性可查看含义与计算说明。

## 设置（F12 → HiddenStats）

| 分组 | 设置 | 默认 |
|---|---|---|
| 1. 通用 | 总开关 / 显示隐藏属性 | 开 / 开 |
| 2. 紧凑属性区 | 压缩原版属性区 / 属性条列数 / 行高比例 / 字号比例 | 开 / 2 / 0.7 / 0.85 |
| 9. 调试（高级） | 输出布局结构 / 调试日志 | 关 / 关 |

## 构建

```bash
dotnet build -c Release HiddenStats.Client/HiddenStats.Client.csproj
```

输出 `HiddenStats.Client/bin/Release/HiddenStats.Client.dll`，复制到 `<SPT 根目录>/BepInEx/plugins/`。
开发说明见 [AGENTS.md](AGENTS.md)。
